# api_to_sql_integration

Integración robusta de datos desde APIs REST a SQL con validación, logging y configuración YAML.

## Estructura
- `src/`: Código fuente y configuración
- `data/`: Datos y logs
- `tests/`: Pruebas unitarias

## Instalación
```bash
uv pip install -r requirements.txt
```

## Ejecución
```bash
python src/api_to_sql.py --config src/config.yaml
```

## Características
- Extracción robusta desde APIs
- Validación y transformación avanzada
- Carga eficiente a SQL
- Logging profesional
- Configuración flexible
- Pruebas unitarias
