# sql_reporting_automation

Automatización profesional de reportes y dashboards SQL con Python. Incluye generación de reportes, visualización, logging y configuración YAML.

## Estructura
- `src/`: Scripts y configuración
- `reports/`: Reportes generados
- `data/`: Datos de entrada
- `tests/`: Pruebas unitarias

## Instalación
```bash
uv pip install -r requirements.txt
```

## Ejecución
```bash
python src/reporting.py --config src/config.yaml
```

## Características
- Generación automática de reportes SQL
- Visualización avanzada
- Logging profesional
- Configuración flexible
- Pruebas unitarias
